Why we built it

Almost everyone in India has seen it in a family or college group: “URGENT! B-ve blood needed, 3 units, call this number, please forward to all groups.” Nobody can tell whether it is still needed. Some of these messages are years old.

The usual explanation is “not enough donors”. But on paper India now collects about as much blood as it needs: 14.6 million units in 2024–25, against an estimated need of about 14.6 million. What breaks is the message. A WhatsApp forward is a frozen copy. It can never say “done”.

2015 → 2021

A 2015–16 blood-donor list went viral again as a “plasma donors” list in 2020, and again in 2021 (Alt News, The Quint, NewsMeter fact-checks).

Since 1998

Paid blood donation is banned in India, yet Kerala Police warned of rising blood-donation scams in July 2025, and Delhi Police arrested a fake donor who took a “convenience fee”.

0.6 / 1,000

Median units in stock per 1,000 people (ORF, 2025), against a WHO benchmark of 10 donations per 1,000. Every real request matters, so people must not learn to ignore them.

So the family’s number keeps ringing after the need is over, scammers use the number to ask for money, and donors start ignoring every request, including the real one tonight. This is a communication problem, and a chat platform can fix it.

What Redsure does

1 · Post onceThe family picks blood group, units, hospital and deadline. One live card appears in their city room.
2 · Share the live linkThey forward a link, not a frozen text. Whoever opens it, even days later, sees the current status.
3 · Donors offer privately“I can donate” opens a private chat with the family. No phone numbers. Money asks get a warning.
4 · It closes itself“+1 unit arranged” … “Fulfilled, please don’t call” updates on every screen and every forwarded link. Unclaimed requests expire.

Check a forward: anyone can paste a forward they received. Redsure reads it (AI + rules), shows blood group, hospital, date and missing details, and says whether it matches a live, fulfilled or unknown request. It never calls a request “fake”; it says what it can and can’t confirm.

Architecture

The server is the single writer of counts, so two donors tapping at the same moment can’t overwrite each other. Only the family who posted can change progress.

What is new here

  • A message that stays true after it is forwarded. Donor apps keep requests inside their own app. Redsure works where requests actually travel: the forwarded link carries the live status, and even the WhatsApp preview shows the current state.
  • Message metadata as the shared state. The card is not a database row shown in a chat. It is the chat message; its progress lives in Nexconn message metadata and changes in place for every member.
  • Closing the loop. Requests end as “Fulfilled”, “Closed” or “Expired”, never in silence. That stops the calls the family gets after the need is over.
  • Safety built into the chat. No phone numbers, a warning on any money ask, and a forward checker that never calls a request “fake” and never invents details it can’t see in the text.

Business and growth

Who uses it

Families who need blood (free, always). Donors who receive forwards. Blood-donor volunteer groups, college NSS units and hospital patient-help desks that today run donor WhatsApp groups by hand.

Who pays (plan)

Blood banks, hospitals and donor NGOs: verified rooms with a “confirmed by blood bank” badge, request dashboards and alerts to donors by blood group and city. Families never pay.

Growth loop

Every shared link is an invitation: a viewer who taps “I can donate” becomes a Redsure user and an active user on Nexconn. One request forwarded to 10 groups reaches hundreds of potential donors.

Roadmap

1) Verified blood-bank rooms. 2) Donor alerts by blood group (Nexconn targeted group messages + push). 3) Same live card for oxygen, rare medicines and platelets. 4) Android app with the Nexconn Flutter SDK.

Honest limits

Built in the challenge window by a one-person team. No real users yet, so we report no traction numbers. Anyone can still post a false request; Redsure reduces harm by hiding numbers, warning on money and closing requests. The free host sleeps when idle, so the first visit can take up to a minute.

Built for this challenge

Everything was built from scratch for the Nexconn Build Challenge 2026. Stack: Nexconn Chat SDK for Web, Node.js/Express server with the Nexconn Platform Chat API, Vite, Groq LLM (optional).
